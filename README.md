# sts_version_control
Buat Branch Baru: Buat branch dengan format jawaban-[nama-siswa_kelas].  Kerjakan Soal: Buat file bernama JAWABAN.md di root folder proyek, lalu isi jawaban dari studi kasus di bawah menggunakan format Markdown.  Commit &amp; Push: Lakukan commit dengan pesan terstruktur, lalu push branch Anda ke GitHub.
